# Gmail contract

nowave depends on Gmail's DOM, URLs, and key handling, none of which Gmail documents. This page lists every such assumption, what nowave uses it for, the evidence for it, and how sure that evidence is. When Gmail changes and nowave breaks, start here. The code for every row is in `src/gmail.js`, `src/route.js`, and, for the Shortwave look, `src/skin.js`.

Each row has one of these confidence labels:

- **confirmed-by-source**: a maintained open-source Gmail library or the browser source does the same thing.
- **confirmed live**: checked by hand on a live Gmail on the date given, in English Gmail in the Ardia browser unless the row says otherwise.
- **inferred**: follows from a source, but no maintained library does exactly this.
- **guess**: based on what one Gmail account showed. Check it on a live Gmail first.
